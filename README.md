# 강사 배정 현황

교육과정 운영 중 강사 섭외 상태를 한 화면에서 훑어보기 위한 연습용 정적 페이지입니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 강사 카드 목록 화면. 빌드 과정 없이 브라우저로 바로 열립니다. |
| `02_instructors.csv` | 화면에 쓰인 예시 강사 명단. 이름과 메일은 모두 가상입니다. |
| `skills-lock.json` | 이 프로젝트에서 쓰는 에이전트 스킬 목록. |

## 여는 방법

`index.html` 을 브라우저로 열면 됩니다. 서버나 설치 과정이 필요 없습니다.

## 화면 구성

- 강사 한 분이 카드 하나. 성함, 담당모듈, 일정, 장소, 상태를 보여줍니다.
- 카드마다 픽셀 캐릭터 아바타가 붙습니다. 도안은 SVG `<symbol>` 하나이고 사람마다 머리색과 옷색만 다릅니다.
- 상태는 카드 바탕색과 배지 두 곳에 표시됩니다. 회신을 기다리는 상태가 가장 눈에 띄도록 맞췄습니다.
- 위쪽 버튼으로 상태를 걸러 볼 수 있습니다. 버튼 목록과 인원수는 카드에 적힌 상태를 읽어 자동으로 만들어집니다.
- 다크모드와 모션 최소화 설정을 따릅니다.

## 데이터에 대해

`02_instructors.csv` 는 예시 자료입니다. 실제 강사 정보가 아니며, 메일 주소는 전부 `example.com` 입니다.

현재 `index.html` 은 CSV 내용을 직접 담고 있는 정적 파일입니다. CSV 를 고쳐도 화면은 따라 바뀌지 않습니다.
