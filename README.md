# 연습용 화면 모음

교육과정 운영에서 반복되는 일을 한 화면으로 줄여 보는 연습용 정적 페이지입니다. 빌드 과정이 없고, 파일을 브라우저로 바로 열면 됩니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | **정산 퀘스트.** 월별로 남은 정산을 퀘스트처럼 하나씩 처리하는 화면. 배포 주소의 첫 화면입니다. |
| `dummy-data.js` | 정산 화면이 쓰는 예시 정산내역 12건. 고객사·강사·계좌번호까지 전부 지어낸 값입니다. |
| `spec.md` | 정산 퀘스트 화면의 기획서. 목표 / 입력 / 단계 / 출력 네 칸으로만 적었습니다. |
| `roster.html` | **강사 배정 현황.** 강사 섭외 상태를 카드로 훑어보는 화면. |
| `02_instructors.csv` | 강사 명단 화면에 쓰인 예시 자료. 이름과 메일은 모두 가상입니다. |
| `skills-lock.json` | 이 프로젝트에서 쓰는 에이전트 스킬 목록. |

## 여는 방법

`index.html` 이나 `roster.html` 을 브라우저로 열면 됩니다. 서버나 설치 과정이 필요 없습니다.

## 정산 퀘스트 (`index.html`)

- `정산 퀘스트 만들기` 를 누르면 아직 정산이 끝나지 않은 건만 월별로 묶여 나옵니다.
- 남은 정산 / 완료된 정산을 탭으로 갈라 봅니다. 위쪽 현황판과 월별 막대로 진행도를 보여줍니다.
- 줄마다 `완료 처리` 와 `수정` 이 붙습니다. 완료하면 동전이 튀고 완료 탭으로 넘어갑니다.
- `정산 상세` 를 펼치면 강사료부터 은행까지 정산에 필요한 14개 칸이 모두 보입니다.
- **눌러도 저장되는 것은 없습니다.** 미리 넣어 둔 문장만 뜨고, 새로고침하면 처음 상태로 돌아갑니다.

## 강사 배정 현황 (`roster.html`)

- 강사 한 분이 카드 하나. 성함, 담당모듈, 일정, 장소, 상태를 보여줍니다.
- 카드마다 픽셀 캐릭터 아바타가 붙습니다. 도안은 SVG `<symbol>` 하나이고 사람마다 머리색과 옷색만 다릅니다.
- 상태는 카드 바탕색과 배지 두 곳에 표시됩니다. 회신을 기다리는 상태가 가장 눈에 띄도록 맞췄습니다.
- 위쪽 버튼으로 상태를 걸러 볼 수 있습니다. 버튼 목록과 인원수는 카드에 적힌 상태를 읽어 자동으로 만들어집니다.

두 화면 모두 다크모드와 모션 최소화 설정을 따릅니다.

## 데이터에 대해

`dummy-data.js` 와 `02_instructors.csv` 는 전부 예시 자료입니다. 실제 회사 자료가 아니며, 고객사명·강사명·계좌번호·메일 주소 모두 지어낸 값입니다.

`roster.html` 은 CSV 내용을 직접 담고 있는 정적 파일입니다. CSV 를 고쳐도 화면은 따라 바뀌지 않습니다.
